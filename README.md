# 3D Personal Identity Card 🌌

Projeto desenvolvido para explorar conceitos avançados de **CSS 3D**, **Glassmorphism** e **UI Futurista**. O objetivo é criar um componente de identidade pessoal que foge do óbvio, utilizando profundidade e efeitos de luz dinâmicos.

## 🚀 Demonstração

✨ **Acesse o projeto online:** [3D Personal Identity Card](https://gustavodeoliveiradev.github.io/3d-personal-card/)

## 🛠️ Tecnologias
- **HTML5** (Semântico)
- **CSS3** (Custom Properties, Flexbox, Perspective, Clip-path)
- **FontAwesome** (Icons)
- **Google Fonts** (Poppins)

## 🚀 O Desafio (Diário de Bordo)
- **Dia 1:** Refatoração completa da estrutura do tutorial para um design autoral (Cyberpunk/Tech). Implementação de variáveis CSS e redesenho do HUD.
- **Dia 2 (Next):** Implementação de Iluminação Dinâmica via JavaScript.

## 🎨 Design Decisions
- **Estética:** Dark Mode com acentos em Ciano Neon.
- **HUD:** No lugar de elementos circulares comuns, optei por um HUD sutil com linhas finas para reforçar o tema tecnológico.
- **Profundidade:** Camadas de conteúdo separadas por `translate3d` para criar um efeito de parallax real no hover.
